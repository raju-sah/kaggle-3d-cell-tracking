# Biohub research for two submissions — 2026-09-18

## Decision

Best practical direction today: keep the working dual-seed TemporalUNet3D + transformer + ILP pipeline and its spatial TTA, then fine-tune the existing association model conservatively. Compare a low-weight fine-tuned association blend against a stronger blend using the same detections and postprocessing. These are proposed experiments, not demonstrated score improvements. Replacing the entire pipeline with Trackastra or adding an unvalidated global veto is a much larger integration risk.

## What the actual metric rewards

The host explicitly identifies its repository as the official metric implementation. [Host confirmation](https://www.kaggle.com/competitions/biohub-cell-tracking-during-development/discussion/716062).

Node matching uses a 7 μm distance cap and optimal assignment. Final score is adjusted edge Jaccard plus 0.1 times division Jaccard. The node-count correction has coefficient 0.1. Sparse annotations do not imply every edge with an unmatched endpoint is ignored: an incorrect edge can count against an annotated source or target. Division recovery permits a one-frame timing offset, but requires local directed parent/daughter evidence, distinct daughter branches, and no local merges. Edge adjustment is weighted by sample edge counts, whereas division counts are aggregated before computing Jaccard. [Current metric specification](https://raw.githubusercontent.com/royerlab/kaggle-cell-tracking-competition/main/metrics.md).

**Inference:** prioritize reliable associations and detection recall; do not add artificial forks, cross-video edges, or indiscriminately prune real cells to manipulate a proxy.

## Fine-tuning proposal

**Pretrained split audit:** the secondary checkpoint's [split manifest](secondary_seed_weights/unet_transformer/split_0/split_manifest.json) lists all 199 movies for training and 40 for validation, with all 40 overlapping training. Every movie in the current eight-movie proxy is in that training set. The primary public dataset contains no split manifest; its downloaded artifact manifest identifies a 400-epoch snapshot, and the model author describes the 400-epoch anchor as trained on all 199 movies. These diagnostics therefore are **not out-of-fold validation of pretrained models**. A new excluded fine-tuning panel measures incremental adaptation only; it cannot undo pretraining exposure. [Model author's explicit all-train/OOF distinction](https://pilkwangkim.github.io/posts/BioHub-Cell-Tracking-Working-Note-2-OOF-Structural-Diagnostics/), [machine-readable local audit](research_sources_2026-09-18/pretrained_split_audit.json).

The official training implementation already masks supervision to annotated rows/columns, uses a source-axis softmax that permits divisions while preventing competing parents, and applies focal weighting. Its division-row multiplier is currently 1.0. The released original baseline was trained only briefly, although the user's attached checkpoints are later, longer-trained models. [Training implementation](https://raw.githubusercontent.com/royerlab/kaggle-cell-tracking-competition/main/scripts/train_unet_transformer.py), [host baseline documentation](https://github.com/royerlab/kaggle-cell-tracking-competition).

Recommended bounded experiment, subject to measured validation:

1. Freeze the detector/backbone initially; fine-tune the association transformer from its exact existing checkpoint at a reduced learning rate. Keep normalization, positional encoding, downsampling, window length, and sparse-label semantics compatible.
2. Sample annotated divisions more often alongside ordinary transitions. Exclude every held-out validation movie from training; preferably group by embryo/acquisition when metadata supports it. Keep the training split and checkpoint ancestry in the artifact manifest.
3. Evaluate continuation edges and divisions separately, including edge TP/FP/FN and total retained detections. Select checkpoints on paired validation improvement, not training loss or matrix accuracy dominated by negatives.
4. Produce submission A with a conservative association-only blend and submission B with a stronger validated blend. Keep the detector and graph repair settings fixed to identify the effect. If stronger blending fails validation, use a second validated postprocessing variant instead of promoting it blindly.

These learning-rate, sampling, and blending choices are engineering recommendations, not values established as optimal by the sources.

For a short Colab run, cache frozen U-Net features at detected centroids. Train parent classification per matched target, allowing both daughters to select the same parent. Keep detected nearby alternatives as distractors and mask targets whose parent is unannotated. Consider baseline-distribution distillation to limit forgetting; this is a proposed regularizer, not a proven gain.

## Time-saving data and current metric implementation

Kaggle CLI's competition file listing exposes individual frame chunks, e.g. `test/44b6_0113de3b.zarr/0/c/0/0/0/0` is 4,469,062 bytes. Download selected train frame chunks with `kaggle competitions download -c biohub-cell-tracking-during-development -f <path>`, plus Zarr metadata and complete GEFF labels; do not wait for the entire competition ZIP for a bounded training experiment. At that example size, 24 clips × 20 frames is roughly 2.1 GB, an estimate rather than the full dataset's measured size.

Current official metric sources have been saved in [research_sources_2026-09-18](research_sources_2026-09-18). `division_metrics.evaluate_divisions(pred_graph, gt_graph, scale=(1.625, 0.40625, 0.40625), max_distance=7.0)` returns `DivisionCounts(tp, fn, fp)`. It imports `polars` and `tracksdata`. Replace historical weak-component proxy logic with this current implementation; the author's July working notes themselves describe older division semantics and must not override the current official code. [Official source](https://raw.githubusercontent.com/royerlab/kaggle-cell-tracking-competition/main/src/tracking_cellmot/division_metrics.py).

## Alternatives deliberately deprioritized today

Trackastra supports pretrained models and custom training, but its standard training path expects CTC instance-mask/tracklet data, whereas this competition supplies sparse centroids. Conversion and domain validation would be additional work. [Trackastra maintainer documentation](https://github.com/weigertlab/trackastra).

The local [HOCT consensus notebook](reference_kernels/sjlee101/biohub-lf-hoctveto-div-b.ipynb) can remove pipeline edges absent from HOCT, including divisions in its aggressive mode. Without measured improvement, this veto can trade existing correct links for fragmentation. It is a separate future ablation, not a justified automatic addition to today's two submissions.
